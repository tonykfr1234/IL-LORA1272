PHP 閘道啟動方式（2026-10-22 更新）

請在儲存庫根目錄使用：
  python scripts/init_env.py
  docker compose up --build -d --wait

主頁：http://127.0.0.1:8080/
CES：http://127.0.0.1:8080/ces/
設定與密碼放在本機 .env。若 .env 已存在，init_env.py 會保留設定並結束，毋須重新產生。
不要再啟動舊廠商容器；新環境不公開資料庫連接埠、不安裝 phpMyAdmin。
API 寫入需要 IOT_API_KEY，HTTP 採集範例透過 X-API-Key header 傳送。
USB 模組與舊 Python 2 硬體函式庫需另外驗證，不由 Web 容器自動操作。

既有資料的備份、InnoDB／utf8mb4 遷移與測試限制：
  docs/PHP_UPGRADE_zh-TW.md（儲存庫根目錄）
