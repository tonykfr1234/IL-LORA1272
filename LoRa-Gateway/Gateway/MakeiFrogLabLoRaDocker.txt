PHP 閘道建立方式（2026-10-22 更新）

本分支改用官方 PHP 8.4.27 Apache／mysqli 與 MariaDB 11.4.13 映像，版本與 digest 固定。
在儲存庫根目錄執行：
  python scripts/init_env.py
  docker compose up --build -d --wait
  docker compose exec web php -v

本機設定保存在 .env；不可上傳。新資料庫是空表，舊資料請先備份並手動遷移。
舊的 PHP 安裝命令、共用預設密碼、過期 phpMyAdmin 與第三方容器方式已停止使用。
完整說明：儲存庫根目錄的 docs/PHP_UPGRADE_zh-TW.md。
LoRa USB 採集需另行設定實體裝置與環境變數，Web 容器不會自動啟動硬體程式。
